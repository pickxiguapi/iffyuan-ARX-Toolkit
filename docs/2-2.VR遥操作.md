# 2-2. VR 采集

VR 链路使用底层 ROS2 VR SDK 节点控制机器人，Toolkit 侧只做数据采样并保存为 Zarr，schema 与主从采集一致。

## 快速开始

```bash
# 1. 机器 B 上拉起 CAN、body/lift、VR arm control、VR SDK、相机节点
bash scripts/collect_VR.sh

# 2. 另开一个终端开始采集
python scripts/collect_vr.py \
    --dataset datasets/take_part_bricks_vr.zarr \
    --arm-mode dual \
    --action-mode absolute_joint \
    --cameras camera_h camera_l camera_r \
    --task "take apart the building bricks"
```

`collect_VR.sh` 会启动 `/ARX_VR_L`、`/ARX_VR_R` 相关控制链路。确认 VR SDK、双臂状态和相机流都有数据后，再运行 `collect_vr.py`。

## 架构

```
VR SDK / arm control ROS2 nodes
    ├── 控制双臂、底盘、升降
    ├── 发布 arm_status_l / arm_status_r / body_information
    └── 可选发布 /ARX_VR_L / /ARX_VR_R
              ↓
ARXEnv public API
    ├── get_observation()
    └── 不发送 VR 控制命令
              ↓
collect_vr.py
    ├── 定频采样
    ├── action_mode=absolute_joint/absolute_eef 选择 action_left/action_right 的语义
    └── 写入 Zarr 数据集
```

## 交互流程

```
Press Enter to start VR dual-arm recording
  ↓
倒计时
  ↓
Recording started
  └── Enter 停止当前 episode
  ↓
Save episode? [y] save / [n] discard / [q] quit
```

## 命令行参数

```
--dataset, -d      Zarr 数据集路径
--arm-mode         dual 或 single
--leader-side      single 模式下只保存该侧 action，另一侧 action 置零
--action-mode      absolute_joint 或 absolute_eef，决定 action_left/action_right 的字段语义
--fps              采样频率
--max-frames       单个 episode 最大帧数，0 表示不限
--max-episodes     本次最多保存 episode 数，0 表示交互式不限
--cameras          相机名列表
--with-depth       保存 aligned depth
--image-size W H   保存图像尺寸
--task             写入 meta config 的任务描述
--include-base     保存 VR base command 到 action_base/action_lift
--countdown        开始录制前倒计时秒数
--no-tts           关闭 spd-say 倒计时语音
```

## Zarr 字段

VR 采集写入与主从采集一致的 Zarr 字段：

```
dataset.zarr/
├── data/
│   ├── rgb_camera_l / rgb_camera_h / rgb_camera_r
│   ├── depth_camera_l / depth_camera_h / depth_camera_r   # --with-depth
│   ├── left_eef_pos / right_eef_pos
│   ├── left_joint_pos / right_joint_pos
│   ├── left_joint_qvel / right_joint_qvel
│   ├── left_joint_effort / right_joint_effort
│   ├── base_height
│   ├── action_left / action_right
│   ├── action_base / action_lift
│   ├── timestamp
│   └── episode
└── meta/
    ├── episode_ends
    └── config
```

`{side}_joint_pos`、`{side}_eef_pos` 和 action 里的夹爪都是 Toolkit 统一的 `[0, 1]` 表示，`0` 为张开，`1` 为闭合。底层硬件的 `[-3.4, 0]` 不直接写入数据集。
